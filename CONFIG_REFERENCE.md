# VupeCore 2.1 configuration reference

Important commerce files:

```text
economy.yml       native Money, selling and economy behavior
shops.yml         full native shop catalog + other shop systems
crates.yml        native crate definitions/rewards/animations/keyall
auctionhouse.yml  native bidding/escrow/claims/search/sort
autosellchests.yml
crystalshop.yml
store.yml
```

### Reload

Use:

```text
/vupe reload
```

Use a full server restart after replacing plugin JARs or changing dependency
versions.

Do not use Bukkit `/reload`.
